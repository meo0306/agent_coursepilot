# Codex 计划批准后的继续执行 Prompt

按刚才已批准的计划执行当前阶段，不扩大范围。

执行要求：

1. 先重新检查 Git 状态，避免覆盖用户在计划讨论期间产生的改动；
2. 按任务 ID 顺序实现，阶段内保持可运行；
3. 每完成一个独立子模块就运行对应专项测试；
4. 遇到非破坏性的实现细节空白，采用最小、可配置、可回滚方案并记录；
5. 遇到产品边界、跨服务合同、Gold 口径、安全或破坏性迁移冲突时，停止该冲突部分，完成其他安全任务并在 Decision Log 候选中说明；
6. 不执行 git commit/push/PR，除非我另行明确要求；
7. 完成后运行阶段 Prompt 中的全部验收命令；
8. 更新 `EXECUTION_STATUS.md`、`RISK_REGISTER.md` 和阶段报告；
9. 最终按 Master Rules 要求报告任务、文件、测试、指标、风险和 Exit Gate。
