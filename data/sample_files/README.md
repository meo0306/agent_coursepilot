# P00 Local Sample Inputs

This directory is the local input boundary for the P00 B0 smoke run.

Expected inputs:

- exactly one non-empty `.docx` file;
- exactly one non-empty `.pdf` file;
- the two files contain different source material and are evaluated independently.

The source binaries are ignored by Git because their copyright and redistribution status have
not been verified. Do not copy their content into reports, fixtures, logs, or generated baseline
artifacts. The B0 manifest may contain only repository-relative paths, media type, byte size,
SHA-256, and an explicit `local_only_unverified` redistribution status.

These files are smoke-test inputs and future DS0 candidates. They are not approved corpus
documents and do not define evaluation Gold.
